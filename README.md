
# Plumbing & Electrical Services Platform

A web-based plumbing and electrical services management platform serving Gauteng, South Africa.

## Technology Stack

### Frontend
- HTML5
- CSS3
- Vanilla JavaScript

### Backend
- PHP
- PDO for database connectivity

### Database
- MySQL

### Development Environment
- XAMPP
- Apache
- Visual Studio Code
- Git and GitHub

## Main Application Areas

1. Public Website
2. Customer Portal
3. Admin Dashboard
4. Technician Portal

## Main Features

- Customer registration and authentication
- Customer profiles and addresses
- Plumbing and electrical services
- Service pricing
- Quotation requests and quotations
- Emergency reports
- Appointment requests and bookings
- Technician management
- Job assignments and progress tracking
- Notifications
- Administrative management

## Local Development

1. Install XAMPP.
2. Start Apache and MySQL.
3. Clone this repository into XAMPP's htdocs directory.
4. Open the project in Visual Studio Code.
5. Visit:

http://localhost/plumbing-electrical-platform/public/
